2. Tipografia

2.1 Fontes Principais

Lora

Família: Serif

Uso: Títulos (h1, h2, h3, h4)

Características: Transmite tradição, confiança e autoridade

Lato

Família: Sans-serif

Uso: Corpo de texto, interface

Características: Legibilidade e modernidade

2.2 Hierarquia Tipográfica

Elemento Fonte Peso Line Height Letter Spacing
H1 Lora 700 (Bold) 1.2 -0.01em
H2 Lora 600 (SemiBold) 1.2 -0.01em
H3, H4 Lora 500 (Medium) 1.2 -0.01em
Body Lato 400 (Regular) 1.6 0.01em
Labels Lato 600-700 1.4 0.05em (uppercase)

3.2 Padrão de Alternância

O site segue um padrão claro-escuro-claro para criar ritmo visual:

HEADER
#0A192F - Header fixo com blur
HERO
#0A192F - Overlay sobre imagem
SEÇÃO CLARA
#FFFFFF - Conteúdo principal
SEÇÃO NEUTRA
#e2e8f0 - Informações, sobre
DESTAQUE / CTA
#0A192F - Call-to-action
PARCEIROS
#e2e8f0 - Seção de parceiros
FOOTER
#0f172a - Rodapé

Princípio: A alternância entre blocos claros e escuros cria separação visual clara e dá destaque às seções mais importantes.

4. Elementos de Interface

4.1 Botões

Tipo Background Hover Uso
Primário #0f172a #1e293b Ações principais (Enviar, Confirmar)
Urgência #E60000 #cc0000 Assistência Técnica
WhatsApp #f8fafc + borda Borda verde Contato rápido

4.2 Cards e Containers

  • Background: #ffffff (branco)
  • Borda: 1px solid #e2e8f0
  • Border-radius: 8px (rounded-lg) ou 4px (rounded-sm)
  • Sombra: shadow-md ou shadow-lg

4.3 Efeito Glass (Glassmorphism)

.glass { background: rgba(255, 255, 255, 0.9); backdrop-filter: blur(10px); border: 1px solid rgba(0, 0, 0, 0.08); box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1); }

4.4 Estados de Hover

  • Transições suaves: transition-colors, transition-all
  • Bordas que mudam para #1e3a8a (border-blue-900) no hover
  • Backgrounds que escurecem levemente
  • Sombras que aumentam em cards interativos
